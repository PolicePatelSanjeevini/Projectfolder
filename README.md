# Java Mini Projects Portfolio

This repository contains three small Java projects developed as part of practice and learning exercises: **Hangman Game, To-Do List Application, and Number Guessing Game**.

---

## 1. Hangman Game

A simple console-based Hangman game where the player guesses a hidden word one letter at a time.

**Features:**
- Tracks correct and incorrect guesses.
- Limited number of attempts.
- Displays the current state of the word and missed letters.
- Predefined list of words for gameplay.

**Technologies Used:**
- Java
- Arrays and Strings
- Console Input/Output

**Learning Outcomes:**
- Practiced loops, conditionals, and string manipulation.
- Implemented basic game logic and user interaction.

---

## 2. To-Do List Application

A console-based To-Do List application to manage tasks effectively.

**Features:**
- Add, edit, and delete tasks.
- Mark tasks as complete.
- View current tasks along with their status.
- Save tasks to a file for data persistence.

**Technologies Used:**
- Java
- File Handling
- Object-Oriented Programming (OOP)

**Learning Outcomes:**
- Practiced OOP concepts like classes and objects.
- Implemented CRUD operations and file storage.
- Improved understanding of task management applications.

---

## 3. Number Guessing Game

A console-based game where the player guesses a randomly generated number.

**Features:**
- System generates a random number within a given range.
- Provides hints (higher/lower) for each guess.
- Tracks the number of attempts.
- Congratulatory message on correct guess.

**Technologies Used:**
- Java
- Random number generation
- Loops and conditionals
- Console Input/Output

**Learning Outcomes:**
- Strengthened problem-solving and algorithmic thinking.
- Practiced loops, conditionals, and input handling in Java.
